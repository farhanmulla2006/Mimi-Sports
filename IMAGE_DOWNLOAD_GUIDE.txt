OPTION A: QUICK METHOD (Recommended Start)

OPTION C: AMAZON / EBAY (Reference Only)
-----------------------------------------
1. Search Amazon/eBay for the product

   Instead, use their images as REFERENCE to find similar

OPTION D: FREEPIK / PIXABAY

1. Go to Pixabay.com or Freepik.com
2. Search for product category/terms
3. Filter by "Free" license (if on Freepik)

TROUBLESHOOTING:
================

Image doesn't show in browser:
→ Check filename is EXACT (lowercase, hyphens)
→ Verify file is in correct sport folder
→ Refresh browser page (Ctrl+Shift+R to clear cache)

Can't find image for a specific product:
→ Try different search terms from checklist
→ Try different sources
→ OR: Use AI generation tool (Leonardo.AI, Replicate, etc.)

Unsplash/Pexels search returns no results:
→ Broaden search terms
→ Search for category instead (e.g., "sports equipment" instead of brand name)
→ Try alternative sources

File is wrong format:
→ Save ONLY as .jpg or .jpeg (not .png, .gif, .webp)
→ Use online converter if needed: CloudConvert.com
